# Автозагрузчик профиля Госуслуг

100% автономный инструмент для загрузки двух страниц профиля с Госуслуг и объединения их в единый офлайн-сайт.

## Какие страницы загружаются

1. **Личные данные** — `https://lk.gosuslugi.ru/profile/personal`
2. **Документы (Паспорт РФ)** — `https://lk.gosuslugi.ru/profile/personal/id-doc`

## Как это работает

1. **Запуск** → Открывается браузер со страницей авторизации Госуслуг
2. **Авторизация** → Вы входите в аккаунт в открывшемся окне
3. **Enter** → Нажимаете Enter в консоли после входа
4. **Автоматическая загрузка** → Скрипт скачивает обе страницы со всеми ассетами (CSS, шрифты, изображения)
5. **Очистка** → Удаляются динамические скрипты Angular, перезаписываются пути
6. **Сборка** → Генерируется и инъектируется `offline.js` для навигации между страницами

## Навигация в офлайн-режиме

- На странице «Личные данные» клик по карточке **«Паспорт РФ»** → переход на страницу документа
- На странице документа кнопка **«Назад»** → возврат на предыдущую страницу

## Установка зависимостей

```bash
pip install playwright beautifulsoup4 aiohttp lxml
playwright install chromium
```

## Запуск

```bash
cd autoload
python run.py
```

## Результат

Готовый офлайн-сайт сохраняется в `autoload/output/`.

## Структура

```
autoload/
├── run.py          # Точка входа
├── loader.py       # Основной модуль (авторизация, загрузка, очистка, сборка)
├── README.md       # Этот файл
└── output/         # Сгенерированный офлайн-сайт (создаётся автоматически)
    ├── profile/
    │   ├── personal.html
    │   └── personal/
    │       └── id-doc.html
    ├── offline.js
    └── ... (ассеты: CSS, шрифты, изображения)
```
